Comandos do Termux

Instalação normal

Instala os pacotes e inicia o agente.

pkg install -y python curl tesseract && curl -fsSL {{ base }}/agent.py -o /sdcard/Download/ldphone_agent.py && python /sdcard/Download/ldphone_agent.py {{ base }} {{ pair }}

Reinstalação limpa

Fecha primeiro o agente no Termux. Apaga os scripts e dados locais deste projeto, instala novamente e cria uma nova ligação; depois podes remover o LDPhone antigo do painel.

rm -f "$HOME/.brawl_room_agent_token" "$HOME/.brawl_room_tactics.json" /sdcard/Download/ldphone_agent.py /sdcard/Download/capture_login.py /sdcard/Download/capture_login_v2.py /sdcard/Download/capture_login_run.log /sdcard/Download/brawl_spy.py /sdcard/Download/brawl_spy.pcap /sdcard/Download/brawl_spy.log /sdcard/Download/brawl_spy_ids.json /sdcard/Download/dump_libg_tail.py /sdcard/Download/frida.log && pkg install -y python curl tesseract && curl -fsSL {{ base }}/agent.py -o /sdcard/Download/ldphone_agent.py && python /sdcard/Download/ldphone_agent.py {{ base }} {{ pair }}
